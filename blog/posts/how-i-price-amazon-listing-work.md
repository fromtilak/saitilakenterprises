Every new seller asks some version of the same question: why does one listing cost ₹500 and another cost ₹2,000? Here's the honest breakdown.

## It's not about the product. It's about the work.

A single-variation listing with a clean title, five bullet points, and a description takes maybe 45 minutes once you know what you're doing. A 12-variation clothing listing with size and colour combinations, backend keywords for each ASIN, and a flat file upload that has to go through without errors — that can take three or four hours, and one small mistake in the flat file means the whole batch gets rejected.

So the price isn't about how "important" the product is. It's about:

- **Number of variations** — more child ASINs means more backend work, not just more images
- **Whether the catalog already has issues** — a fresh listing is faster than fixing someone else's broken flat file
- **Content depth** — five generic bullet points versus keyword-researched, conversion-focused copy are two different jobs
- **Category restrictions** — some categories need approval, compliance documents, or specific attribute mapping that eats time

## What ₹500 actually gets you

At the base tier, you're getting a single listing done properly — title, bullets, backend search terms, and image slots mapped correctly. It does not include product photography, brand registry work, or ongoing optimization. That's a separate conversation, usually billed as ads support or a monthly retainer.

## Why I don't do "per hour"

Sellers don't want to track hours, and honestly, neither do I. A fixed price per listing means you know the number before anything starts, and I'm not incentivized to drag out simple work. If a listing turns out to be more complex than described — more variations, missing product info, category approval needed — I'll tell you before starting, not after.

## The real lesson

If you're comparing quotes between freelancers, don't just compare the number. Ask what's included: is it one listing or the whole variation family? Does it include backend search terms? Is there a revision round if the first draft needs a tweak? A ₹300 quote that doesn't include backend keywords is not actually cheaper than a ₹500 quote that does — you'll just end up paying for it twice.
